# SOUL snippets

Paste these sections into each profile's `SOUL.md`, outside any tool-managed marker block
(for example after `<!-- omh:agent-instructions:end -->`). Every worker reads its profile's SOUL,
including follow-up cards that skills never touch, which is why these rules live here and not
only in the skills.

- `ask-dont-block.md`: needing the user is a questionnaire, never a stop.
- `goal-ledger.md`: finish goal work through `goals.py` (the met rule).
- `review-handoff.md`: the review handoff is the goal's last step (avoids the circular review gate).
- `scratch-hygiene.md`: keep scratch out of `~/.cache` and delete build outputs at card end.
